# A finding made late, and the follow-up lists

- **When:** A finding is made in steps 10 to 14.
- **Check it runs:** the lateness script; the follow-up lists.
- **Detected by:** lateness script.

- **Follow-up lists.** A change found after step 9, in steps 10 to 14, goes on a follow-up pair of lists, numbered
  on from the last items (for example M24…, C9…). It is built and checked as in step 8, and shown to the user as
  soon as it is ready, in one message with any others found close together. Work that does not depend on it goes
  on. Once approved, it is written as in step 9, and steps 10 to 12 run again for the rules it changes. The run
  ends "incomplete" only for items the user has not answered, or chose to leave for a later run. Every late finding
  first goes through the lateness script (tools: lateness script): one that step 7 should have found sends step 7's
  complete check back.

**Late findings go through the lateness script.** The finding itself goes on the follow-up lists if it is
conceptual, or back to step 11 if it is mechanical.

*The follow-up lists, as the way late decisions are asked in the same run, are a reading of the user's words
("don't stop until you get that fully set up"; "Don't stop until [it's] done"), waiting for confirmation on list C
(audit fix 9).*
